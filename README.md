# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST).

The site is built with [Jekyll](https://jekyllrb.com) and the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (itself a fork of the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme), and is hosted on GitHub Pages.

## Site content

* `_pages/about.md` — home / about page: personal details, research interests and skills, education, research experience, publications, honors and awards, and contact information
* `_pages/publications.html` — publications listing page
* `_publications/` — one Markdown file per publication
* `_config.yml` — site-wide configuration (name, bio, affiliation, email, Google Scholar, GitHub, X)

## Running the site locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open <http://localhost:4000/LJT-Homepage>.
